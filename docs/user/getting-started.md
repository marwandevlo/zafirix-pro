# Getting Started — Zafirix Atlas

Welcome to Zafirix Atlas. This guide helps you become productive in under 10 minutes.

## Quick path

1. Complete your profile at `/onboarding`
2. Run the setup wizard at `/setup` (7 steps)
3. Upload your first invoice at `/documents`
4. Ask the AI Copilot at `/assistant` for help anytime

## Checklist

- Company created (ICE, RC, IF)
- TVA configured
- First document uploaded
- First invoice created
- Optional: bank import, payroll run, liasse readiness

## Help

Visit `/help` for searchable articles or use the guided tour from the dashboard.
