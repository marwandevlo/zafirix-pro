# Company Setup

Use `/setup` or **Settings → Company** to configure your legal entity.

## Required fields

| Field | Description |
|-------|-------------|
| Raison sociale | Legal company name |
| ICE | 15-digit Moroccan identifier |
| RC | Registre de commerce |
| IF | Identifiant fiscal (6–8 digits) |
| CNSS | Social security number |
| Address & contacts | For invoices and declarations |

The setup wizard shows a completion score as you fill fields.
