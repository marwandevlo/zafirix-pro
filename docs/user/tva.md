# TVA (Value Added Tax)

Configure TVA during `/setup` step 3 or in module **TVA** (`/tva`).

## Configuration

- **Regime**: mensuel, trimestriel, or exonéré
- **Rates**: 20%, 14%, 10%, 7%, 0% (Morocco)

## Declarations

TVA lines are built from validated invoices. Review periods in the TVA module before filing with your accountant.
