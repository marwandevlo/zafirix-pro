# Documents IA

Upload PDFs or images of invoices, bank statements, and payroll documents.

## Workflow

1. Go to **Documents IA** (`/documents`)
2. Upload a file
3. OCR extracts fields automatically
4. Route to Factures, Banque, or Comptabilité
5. Validate in the Validation Center

## Tips

- Prefer clear PDF scans for best OCR accuracy
- Link documents to clients and companies before routing
