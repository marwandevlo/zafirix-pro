# Business Studio — feature completion matrix

Branch `feature/business-studio`, based on production `4fe5012`. Engine `studio-engine-1.0.0`, tax rules `ma-studio-rules-2026.11-v1`.

Status meanings:
- **Done**: implemented and verified by the evidence listed.
- **Partial**: works as described, with the gap stated.
- **Not done**: not implemented.

Evidence types:
- **U**: unit test in `tests/business-studio/*.test.ts`.
- **I**: integration test against local Postgres + PostgREST (`tests/business-studio/integration`).
- **H**: HTTP smoke through `next start` (`tests/business-studio/e2e/http-smoke.mjs`).
- **B**: manual browser run on a local production build.
- **E**: automated browser journey (`tests/business-studio/e2e/studio-journey.spec.ts`, Playwright, desktop 1440 px and Pixel 7) on a local production build, with every downloaded file reopened by `inspect-documents.ts`. Results: `E2E_EVIDENCE.md`.

- **R**: visual review of every screen (`tests/business-studio/e2e/studio-review.spec.ts`, French desktop, Arabic desktop, Arabic mobile) and of rendered PDF pages, with figures recomputed by hand.

None of this evidence comes from hosted Supabase or production. **Hosted Supabase verification is untested (not passed).**
