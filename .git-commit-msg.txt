feat: Global Actions System -- EntityActionMenu, ConfirmDeleteDialog, EntityHistoryDrawer

## New reusable components (app/components/actions/)

### EntityActionMenu
- Three-dot (MoreHorizontal) trigger button
- Desktop: absolute dropdown with click-outside close
- Mobile (<640px): slides up from bottom as a portal-rendered sheet
- Item variants: default / danger / warning / success
- Disabled items show 'Bientôt disponible' tooltip

### ConfirmDeleteDialog
- Portal-rendered modal with overlay
- Offers 'Archiver' as a softer alternative to delete
- Keyboard: Esc cancels; Cancel/Archive/Supprimer buttons
- Business-critical data protection by default

### EntityHistoryDrawer
- Right-side panel portal showing event timeline
- Fetches from /api/entities/[type]/[id]/history (generic + zafirix_document_events)
- Event icons + labels for 20+ event types
- Supports propEvents (pre-loaded) or onFetchEvents callback

### ShareExportMenu
- Small Share2 trigger dropdown
- Download PDF / Send email / Copy link actions

### PermissionGuard
- Permission-aware wrapper (owner / admin / viewer / any)
- Forward-compatible with future RBAC system
